Sequence Diagram: Assignment Workflow

Student assignment submission flow with deadline and enrollment validation.

Sequence 
sequenceDiagram
    actor Student
    participant Client as Client / Frontend
    participant API as Express API
    participant Auth as JWT Auth Middleware
    participant AssignmentService
    participant AssignmentRepository
    participant EnrollmentRepository
    participant FileStorage as File Storage
    participant DB as Neon PostgreSQL

    Student->>Client: Select assignment and upload file
    Client->>API: POST /api/assignments/:id/submissions
    API->>Auth: Verify Bearer token
    Auth-->>API: role = student
    API->>AssignmentService: submitAssignment(studentId, assignmentId, file)
    AssignmentService->>AssignmentRepository: findById(assignmentId)
    AssignmentRepository->>DB: SELECT assignment
    DB-->>AssignmentRepository: assignment

    alt Deadline passed
        AssignmentService-->>API: Reject submission
        API-->>Client: 400 Deadline has passed
    else Deadline valid
        AssignmentService->>EnrollmentRepository: findByCourseAndStudent(courseId, studentId)
        EnrollmentRepository->>DB: SELECT enrollment
        DB-->>EnrollmentRepository: enrollment found
        API->>FileStorage: Store uploaded file
        AssignmentService->>AssignmentRepository: createSubmission()
        AssignmentRepository->>DB: INSERT submissions
        DB-->>AssignmentRepository: submission
        API-->>Client: 201 Created
        Client-->>Student: Submission successful
    end

Sequence Diagram: Attendance Workflow

Faculty creates a class session and marks attendance for enrolled students.

Sequence 
sequenceDiagram
    actor Faculty
    participant Client as Client / Frontend
    participant API as Express API
    participant Auth as JWT Auth Middleware
    participant AttendanceService
    participant CourseRepository
    participant AttendanceRepository
    participant DB as Neon PostgreSQL

    Faculty->>Client: Create class session
    Client->>API: POST /api/attendance/sessions
    API->>Auth: Verify token and role
    Auth-->>API: role = faculty
    API->>AttendanceService: createSession()
    AttendanceService->>CourseRepository: findFacultyAssignment()
    CourseRepository->>DB: SELECT course_faculty
    DB-->>CourseRepository: assignment exists
    AttendanceService->>AttendanceRepository: createSession()
    AttendanceRepository->>DB: INSERT sessions
    DB-->>AttendanceRepository: session
    API-->>Client: 201 session created

    Faculty->>Client: Mark attendance
    Client->>API: POST /api/attendance/sessions/:id/records
    API->>AttendanceService: markAttendance()
    AttendanceService->>AttendanceRepository: findSessionById()
    AttendanceRepository->>DB: SELECT session
    AttendanceService->>CourseRepository: findFacultyAssignment()
    CourseRepository->>DB: SELECT course_faculty
    AttendanceService->>AttendanceRepository: saveAttendanceRecords()
    AttendanceRepository->>DB: INSERT/UPDATE attendance_records
    API-->>Client: 200 attendance saved
